# 제품 정의

## 문제

금융투자회사 채용 공고는 게시판 형태로 흩어져 있어 지원자가 마감일과 관심 공고를
한눈에 관리하기 어렵다.

## 목표 사용자

- 증권사, 자산운용사, 투자자문사 등 금융투자업권 취업 준비생
- 여러 회사의 경력직 공고를 동시에 살피는 실무자

## MVP 가설

공고를 마감일 기준 달력으로 보여주고 검색·필터·관심 저장을 제공하면 사용자가 놓치는
마감일을 줄이고 매일 게시판을 다시 탐색하는 시간을 아낄 수 있다.

## 포함 범위

- KOFIA 회원사 채용안내 공고
- 월간 달력과 지원 상태별 목록
- 회사/공고/직무 검색
- 신입/경력 필터
- 로컬 관심 공고 저장
- 원문 링크 제공

## 제외 범위

- 지원서 직접 제출
- 회원가입과 서버 동기화
- 합격 가능성 예측
- 고빈도 수집, 접근제한 우회 또는 원문 전체 재게시

## 데이터 원칙

- 제목, 회사명, 접수 시작일, 접수 마감일, 원문 URL 등 최소 메타데이터만 저장한다.
- 상세 내용은 요약하고 원문을 우선한다.
- 마감일이 없는 공고는 별도 목록으로 분리한다.
- 마감 공고는 삭제하지 않고 최근 마감순 아카이브로 유지한다.
- 공개 게시판은 하루 한 번 낮은 빈도로 확인하고 신규·최근 공고 상세만 요청한다.
- `원문 URL + 회사명 + 제목`을 기준으로 중복을 판별한다.
- 수집 전 사이트 이용 정책과 robots.txt를 확인한다.

## 성공 지표

- 방문자가 관심 공고를 한 개 이상 저장하는 비율
- 원문 공고로 이동하는 비율
- 7일 내 재방문율
- 마감일 누락/오인 신고 건수
